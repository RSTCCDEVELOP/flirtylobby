3. Pages, menu and edit mode

This chapter explains how pages and the menu work in Easy2edit, and how to build and edit page content using edit mode.

Pages and menu overview

Go to Admin > Pages to manage everything related to your site structure. This is where you find:

  • System pages, such as Home and products, which are part of the core setup of your site.
  • Own pages, which are simple text pages available at an address such as /p/<key>.
  • Links and menu items, which let you point the menu to internal pages or external addresses without creating a full page.

Page settings

Each page has its own set of settings that control how it looks, who can see it and where it appears.

  • Names per language. You can set a different name for each language, and use AI translation to automatically translate the name into all other active languages.
  • Address per language. Each language can have its own address for the page.
  • Visibility. Choose who may see the page: everybody, only logged-in users, only guests, or specific users or groups.
  • Menu display. Decide whether the page should show in the header menu.
  • New tab. Choose whether the page should open in a new browser tab when clicked.
  • Devices. Control whether the page is shown on desktop, tablet and/or mobile.
  • Theme, header and footer. A page can use its own theme, header or footer instead of the site-wide default.
  • SEO per language. Set SEO details separately for each language.
  • Background. Add a background image or video to the page.

Switching on edit mode

To start editing the content of a page, click the pencil icon in the header. This switches the page into edit mode, where you can add, change and arrange content directly on the page.

Rows, cells and items

Pages in Easy2edit are built from rows, which act as horizontal blocks of content.

  • Each row can be divided into cells, from 1 up to 4 columns.
  • Each cell can contain one or more items, which are the actual pieces of content.

Available items include:

  • Heading
  • Text (rich text)
  • Image
  • Button
  • Spacer
  • Line
  • System objects
  • Ready-made parts: contact data, social media, map, video, quote, figures, logo, opening hours
  • HTML / CSS code

Row settings

Click the gear icon in the corner of a row to open its settings. From here you can adjust:

  • Background colour, image or video
  • Overlay
  • Padding
  • Width: column, wide or full screen
  • Hero height
  • Text colour
  • Rounded corners
  • Space above the row

Cell settings

Each cell within a row also has its own settings, including:

  • Width
  • Alignment
  • Card style: background, border, radius and shadow

Text and button settings

Text items can be styled individually with:

  • Style, size, colour and font
  • Padding
  • Background, shown as a label or pill

Button items can be configured with:

  • Label per language
  • Link
  • Style: primary, outline or ghost
  • Colours
  • Size
  • Icon

The HTML / CSS code part

For advanced or custom content, you can add the HTML / CSS code item. This opens a large pop-up with three tabs:

  • Visual. Click directly in the text area and type; this works as what you see is what you get. A toolbar offers bold, italic, underline, list, link and clear formatting, plus a light or dark background switch.
  • HTML. Edit the underlying HTML code directly.
  • CSS. Edit the styling for this piece of content.

The code you enter runs inside a sandboxed frame, which means it has no rights on the rest of the site. This keeps your website safe even when custom code is used.

System objects

System objects let you place dynamic, module-based content into a page. These must first be enabled in Admin > System objects. Available system objects include:

  • Donation buttons
  • Subscriptions
  • Media views
  • Plugin parts
  • AI dashboard blocks (visible to superadmins only)

To add one, go into edit mode on a page and choose + Add > System objects, then select the object you want to place.

Editing pages imported from HTML

If a page was taken over 1 to 1 from an HTML file during site import, it behaves slightly differently in edit mode. Every text and button on such a page shows its own pencil icon.

  1. Click the pencil next to the text or button you want to change.
  2. An editor opens showing the content as it appears on the page, with formatting options for bold, italic, underline and link, and for buttons, the link address.
  3. Make your changes in the editor.
  4. Click Save to write the changes back into the page.

This approach lets you safely update imported HTML pages without needing to rebuild them with rows and cells.
