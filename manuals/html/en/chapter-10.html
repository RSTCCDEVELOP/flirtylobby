10. AI and AI credit

easy2edit uses artificial intelligence, powered by Claude (Anthropic), throughout the system. It helps with translating content, writing page texts, importing websites, researching prices and more. Because AI calls have a real cost, every call is logged and, in most cases, paid for with AI credit.

Video: AI and AI credit (English voice-over also in Nederlands)

How AI is switched on#

AI is a core module. It becomes active automatically as soon as an AI link (an API key) is installed and enabled under Admin > API keys.

A link can be marked as a Superadmin link. In that case only superadmins can see or change it. This is used, for example, for the easy2edit AI link and the Stripe link of the reseller, which must stay out of reach of regular admins.

When a superadmin has an easy2edit AI link installed, all AI calls made by users and admins run on that link. This keeps billing and monitoring centralised unless an admin has set up their own AI link, as described further below.

Monitoring every call#

Every single call to the AI is recorded, including:

  • Who made the call: a user, an admin, a superadmin, or the system itself
  • From which part of the system the call came
  • Which AI model was used
  • Tokens sent in and tokens received out
  • How long the call took
  • Whether it succeeded
  • What it cost

This information feeds the Super admin > AI dashboard.

The Super admin AI dashboard#

Superadmins manage AI through Super admin > AI, which has these tabs:

  • Overview: key figures, cost over time per group, share of use per group, and the last calls made
  • Where: where AI is used most, what costs most, which tasks and models are involved, and the busiest hours and weekdays
  • Users: heavy users, highest costs, and a table per user with a PDF button on each row
  • Costs: costs broken down per month or week, per group, and per user
  • Credit: management of AI credit balances
  • Blocks: dashboard blocks that can be placed on pages
  • Settings: pricing and margin configuration

The dashboard can be filtered by period, by month (the current month plus the twelve before it), and by group. The PDF button produces a summary; choosing 'Detailed' produces a complete list of every call with tokens in and out, duration and costs.

Costs, pricing and margins#

Superadmins configure purchase prices per million tokens per model under the Claude, OpenAI and Gemini tabs, matching whichever models are active in the connected API. The 'Refresh models' button looks up current prices directly from the AI provider.

Purchase prices are set in the purchase currency (for example USD), while sale prices are set in the selling currency (for example EUR), using an exchange rate that can be updated with a button that asks the AI for the current rate.

Three separate margins can be set, each split between tokens in and tokens out:

  • Users
  • Admins
  • Reseller/superadmin

A switch decides whether superadmin and system use is also charged to the customer. When switched on, this use is booked to a group named after the website, with the reseller margin applied. When switched off, this use is a cost to the reseller with no margin, shown separately.

Prices, exchange rate and margins are stored with each individual call, so any later change to settings only affects new calls, never past ones. Only superadmins can change these AI settings.

AI credit#

By default, users and admins must buy AI credit before they can use AI features. Superadmins and the system itself never need credit.

Before every AI call, the system estimates its cost and checks it against the available credit. If there is not enough credit, nothing is sent, and a message explains how much is needed.

After the call completes, the actual cost is deducted from the credit balance.

When a user's credit is low, a pop-up appears with a slider to top up, offering a minimum of 25, 50 or 100 based on the user's usage over the last 30 days, along with a suggested amount.

Payment always runs through Stripe using an easy2edit link belonging to the superadmin, never the website's own shop Stripe. Credit is added once payment is confirmed, which happens when the customer returns from Stripe and again when the AI screen is opened.

Superadmins set the top-up amounts and can manually add or deduct credit per user via Super admin > AI > Credit.

Every admin sees a welcome pop-up at first login explaining how AI and AI credit work.

On any computer where the sandbox is switched on, AI credit is never paid with a real payment. Instead, the simulated payment page is used.

Each standard installation has an AI tab showing whether AI belongs to that installation, whether credit is required, and the smallest and biggest allowed top-up amounts.

What admins can see#

Admin > AI shows the AI use of users and admins, without purchase prices or margin details or any reseller costs. It includes a block called 'AI use' on the Admin start page, showing the admin's own credit, a table per user and a PDF report per user that excludes purchase prices.

To see this, an admin needs the right 'View AI use of users', assigned under Roles.

Admins with their own AI link#

An admin who has set up their own Anthropic AI link and their own Stripe link, with neither marked as a superadmin link, can switch on their own credit system for their users via Admin > AI > Credit for users.

In that case:

  • Their users use the admin's own AI link
  • Payments run through the admin's own Stripe account
  • The margin belongs to the admin
  • The admin sets the credit rules, top-up amounts and margin
  • The admin can add credit per user manually

AI blocks on pages#

Parts of the AI dashboard, such as key figures, cost over time, use per group, where AI is used, heavy users, highest costs, models and busy hours, can be switched on as system objects under Super admin > AI > Blocks and placed on any page in edit mode. Only superadmins can see the figures in these blocks.
