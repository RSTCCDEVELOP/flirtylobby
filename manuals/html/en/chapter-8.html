8. Community, marketplace, agenda, documents and games

Easy2edit offers a set of plugins that turn your site into a social platform. Together they let members build a profile, find and contact each other, trade items, manage appointments, share documents and play games. This chapter describes each of these building blocks and how they fit together.

Community overview

The Community plugin brings together everything you need for a community or dating site. Members get their own profile pages with photos, can search for other members, and can block users they do not want to interact with. They can search and match with others: liking profiles, keeping favorites and seeing who visited their page. Members can also exchange messages, use chat, and set up a direct connection (WebRTC) using a code, a link or a QR code.

Community profiles use profile themes, profile fields and "available for" options, so you can tailor the experience to your audience. When parts of the community require a subscription or a donation, the Community plugin works together with the Subscriptions plugin.

Profile themes

Profile themes let you package a set of profile fields and settings for a specific type of community. Easy2edit comes with ready-made themes:

  • Sporters
  • Dating
  • Business
  • Webshop

You can install or remove these themes, or create your own with custom fields, visibility settings and search filters. As superadmin, you decide which themes administrators and users are allowed to choose. Themes can be exported and imported as JSON files, which makes it easy to reuse a theme on another site or share it with others.

Marketplace

The marketplace lets members offer products, services or other items for sale. Each listing can have its own theme and images. Sellers can choose how an item is offered:

  • A fixed price
  • Bidding, starting from a minimum price
  • A booking, for example an appointment or registration for an event

Bids are visible to all members, so the marketplace works in an open, transparent way, similar to an auction.

Agenda

The agenda gives users and groups a way to manage appointments and events. It supports several types of entries:

  • Personal appointments
  • Appointments with other members, including invitations, confirmations or proposing an alternative time
  • Group appointments
  • Events created by administrators, which can be placed on pages as a system object

The agenda includes reminders and notifications, and members can see upcoming items through a tile on the dashboard.

Document management

Document management allows you to upload documents into a folder structure, complete with tags, version history and access rights per user or per group. Files can be stored on the server or on S3, and can be encrypted for extra security. Blocks are available so you can display documents directly on pages.

To set up document access for a specific audience:

  1. Create the folder structure that matches how your organization works.
  2. Upload documents and add tags to make them easy to find.
  3. Set rights per user or per group, so only the right people can view or edit each document.
  4. Place a document block on a page if you want visitors to see selected documents there.

Games

The games hall gives your members a place to play. Each game is its own package, delivered as a folder or a zip file containing a game.json file, placed in the games folder of the games plugin. Every game has its own configuration for management and its own settings per member.

Games run in an isolated, protected environment and automatically save scores and progress. Ranked lists let members compare their results, and a sample game is included so you can see how a game package is structured before adding your own.

Age, country and gambling checks

Some community and marketplace features are only appropriate for certain audiences, so Easy2edit includes age verification (18+), country checks and a gambling popup (24+). These checks should only be enabled for the target groups where they are required or desired.

The settings for these checks are found under Admin > Beveiliging (Security). Keep in mind that the popups and the country check only work when the relevant plugin is switched on.

The building blocks behind Community

The Community plugin is built from several smaller plugins, which you can also find and manage individually:

  • Profiles: the personal profile page with multiple photos, visibility per language and group, the member search and the option to block other users.
  • Discover: searching for and meeting other users, similar to a dating site, with filters, recommendations, likes, matches, favorites and visitors.
  • Messages: the messaging system between users, with its own inbox.
  • Chat: chat in a popup or full screen, either through the portal or directly between members using WebRTC, including photos, videos and video chat.
  • Direct connect: a direct WebRTC connection between two people using a code, a link or a QR code, available even without an account. This includes chat, photos, videos and video chat, accessible through the /directconnect and /direct pages.

Because these are separate plugins underneath the Community umbrella, you can enable only the parts you need, or use them independently if you do not want a full community setup.
