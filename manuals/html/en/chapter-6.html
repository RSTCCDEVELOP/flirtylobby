6. Users, roles and security

This chapter explains how to manage who can access your website and your admin area, and how to protect both your visitors and your content with the built-in security tools.

Users

Every person who needs access to the admin area or who has a public profile on the website is set up as a user. In Admin > Users you can:

  • Create new accounts
  • Add a profile photo
  • Block an account temporarily
  • Delete an account permanently

A blocked account cannot log in, but its data and content remain in the system until you decide to delete it. Each user can also have a public profile, which is useful if visitors should be able to see who wrote an article or who moderates a section of the site.

User groups

If several users need the same access, you can organise them into user groups. A group combines a set of roles and module access, so you only need to configure permissions once and then add or remove users from the group as needed. This is the easiest way to manage access for teams, such as editors, moderators or support staff.

Roles

Roles (Admin > Rollen) define exactly what a user or group is allowed to do. A role is a set of rights, for example:

  • Content manager
  • Moderator
  • View AI use of users

Each right unlocks a specific part of the admin area. You can assign one or more roles to a user or to a user group.

If the Rollen module is switched off, only superadmins have any rights at all. Superadmins always have full access to every part of the system, regardless of the roles configured.

Steps to assign a role:

  1. Go to Admin > Rollen.
  2. Open or create the role you want to use.
  3. Add the rights that belong to this role.
  4. Assign the role to the relevant user or user group.

Module access per user or group

Besides roles, access to individual modules can also be granted directly to a specific user or group. This is managed in Super admin > Modules, using the person icon next to a module. This gives you fine control in cases where someone needs access to one particular module without needing a full role.

Dashboard and your own profile

Once logged in, every user lands on their dashboard. From there, users can manage their own profile, including their photo and personal details. The dashboard is also the starting point for reaching the parts of the admin area that the user has rights for.

General security

The Algemene beveiliging module covers the core security settings for the admin area:

  • Login lock: blocks further login attempts after repeated failures, to protect against brute-force attacks
  • Session duration: controls how long a user stays logged in before needing to log in again
  • Password rules: enforce minimum requirements for passwords created by your users
  • Security headers: technical HTTP headers that help protect the website against common attacks

Two-step verification is also available as an extra layer of login security, requiring a second confirmation step in addition to the password.

It is recommended to review these settings when setting up a new site, and to keep password rules and session duration suited to how sensitive the content of your site is.

Country control

The Landcontrole module lets you block or allow access to your website per country, based on the visitor's IP address. This is useful if your content or products are only relevant, or only legally allowed, in certain countries.

Age and gambling checks

Some websites are required to confirm the age of their visitors or to show responsible-use warnings:

  • Leeftijdscontrole shows an 18+ popup to visitors before they can view the site
  • Gokken-popup shows a combined age and warning popup specifically intended for gambling-related content

Enable the module that matches your legal requirements; both can be configured without needing developer support.

Cookies

The Cookies module provides the cookiebanner that visitors see, lets them set their cookie preferences, and links to your cookie policy popup. This helps you meet legal requirements around informing visitors about cookie use and obtaining their consent where needed.

Word filter

The Woordfilter module automatically checks for forbidden words in texts, names and captions entered on your website. This is useful for keeping user-generated content, such as comments, profile names or captions, free of unwanted language without needing to review every entry manually.
