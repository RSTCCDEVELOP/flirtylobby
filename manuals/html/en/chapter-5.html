5. Media, theme, languages and branding

This chapter covers the parts of Easy2edit that control how your website looks and feels, and how your media and content are made available to visitors in different languages.

Media library

The media library is where you manage all images and videos used throughout your website, whether they are stored locally or on an external storage service such as S3.

Every image or video you upload can be given tags, which makes it much easier to find the right file later, especially once your library grows. Once a picture is in the library, it becomes available for selection in every pop-up throughout Easy2edit, so you only need to upload a file once and can reuse it wherever you need it.

Practical tips for working with the media library:

  • Upload images and videos in advance, before you start building a page, so you can simply pick them from the library while editing.
  • Use clear, consistent tags (for example by subject, page, or campaign) so files stay easy to find.
  • Reuse existing media instead of uploading duplicates, to keep your library tidy and save storage space.

Logos and images (branding)

The branding settings let you control the key visual elements that represent your organisation across the website. This includes:

  • The logo, with separate versions for light and dark mode
  • The favicon, shown in browser tabs
  • The app icon, used when the site is saved to a home screen
  • The photos displayed on the homepage

Keeping these elements up to date ensures your website looks professional and consistent, and that your brand is recognisable in browser tabs, bookmarks, and on mobile home screens.

Theme (Admin > Theme)

The theme settings determine the overall look and feel of your website. Here you can adjust:

  • Colours for both light mode and dark mode
  • Fonts used across the site
  • Roundings (how sharp or soft corners and edges appear)
  • Content width
  • Header layout, including an editorial layout with a side menu
  • Pop-up style

If the theme feature is switched off, the website uses the standard style instead of your custom settings.

Theme packs let you change the entire look of your website in one click. Rather than adjusting colours, fonts, and layout settings one by one, you can select a theme pack that applies a complete, coordinated style instantly. This is useful if you want to try out a different look quickly or want to keep a consistent style across multiple projects.

Exporting and importing themes gives you additional flexibility:

  • Export a theme to save your current style settings or to reuse them on another website.
  • Import a theme to apply a previously saved style, which is helpful when managing several websites that should share the same look, or when restoring a style you created earlier.

Steps to apply a theme pack:

  1. Go to Admin > Theme.
  2. Browse the available theme packs.
  3. Select the theme pack you want to use.
  4. Review the result on your website, since colours, fonts and layout will update immediately.

Languages

The languages feature controls whether your website is available in multiple languages or only in a single, default language. If languages are switched off, visitors only see the website in the standard language.

When languages are switched on, you can:

  • Choose which languages your website offers to visitors
  • Set the default language that visitors see first
  • Translate texts using the built-in AI translation feature

This makes it possible to reach a wider audience without manually rewriting every page in each language. The AI translation feature can give you a solid starting point, which you can then review and refine where needed.

It is worth noting that the system itself, meaning menus, labels and other interface texts, is already available in 44 languages. This means administrators and editors can often work in their own language, regardless of which languages are offered to website visitors.

Putting it together

Media, branding, theme and language settings work together to shape the overall experience of your website:

  • Use the media library to organise and reuse your visual content efficiently.
  • Set up logos and images once, and update them whenever your branding changes.
  • Use the theme settings, or a theme pack, to quickly establish a consistent visual style, and export or import themes when working across multiple sites.
  • Decide whether your website needs multiple languages, and if so, configure them and use AI translation to speed up the process.

Taking time to set these up carefully early on will save effort later, since changes here affect the entire website rather than individual pages.
